# La Llave

Sitio / PWA de los playoffs de la Liga Profesional argentina: cruces en vivo, vista en llave y predicción de fechas.

El código es tuyo. Podés seguir cambiándolo acá con Grok, en tu máquina, o en el VPS.

## Correrlo en tu PC

Hace falta Node 22.

```bash
npm install
npm run dev
```

Abre `http://localhost:8080`.

## Publicar en pirata.app (Hostinger VPS)

Cuando quieras lo subimos al VPS. No hace falta que me des la contraseña: el repo ya está en GitHub y desde el servidor se clona y se levanta.
